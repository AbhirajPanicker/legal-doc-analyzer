

Click Terminal in the top menu bar → New Terminal.
Run the Backend:
powershell
cd "d:\Legal Document Analyzer\backend"
.\venv\Scripts\Activate.ps1
uvicorn main:app --reload --port 8000
Open a second terminal (click the + icon on the terminal panel) and run the Frontend:
powershell
cd "d:\Legal Document Analyzer\frontend"
npm run dev
Open your browser and go to: http://localhost:5173
